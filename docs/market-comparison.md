# 뉴스·차트 기본 전략 대 시장지수 필터

버전 `news-chart-market-filter-shadow-v1`. 기존 모의 주문 원장 및 기존 뉴스 대 가격 비교와 다른 새 실험이다. 증권사 주문을 전송하지 않으며 기존 자동매매를 활성화하지 않는다. 2026-10-28 사용자 동의로 구현했다. 수익성이 검증된 규칙이 아니라 사전 고정한 가설이다.

## 사전 고정 조건

- A: 현재 일반 신규 포지션의 종목 차트 규칙 + 최근 뉴스 확인 조건. 뉴스가 중립이어도 분석이 유효하면 허용한다. 제목 기반 분석은 사실 확인/공시 원문 해석과 다르다.
- B: A와 동일하되 시장 기준의 직전 완료 월말 조정종가가 그 월말을 포함한 최근 10개 완료 월말 조정종가 평균을 초과할 때만 신규 진입한다. 동점은 보류. 월중 평가대상 월을 바꾸지 않는다.
- 기준: 국내 모든 관심종목 → KODEX200 `069500.KS`, 미국 관심종목 → SPY `SPY`. ETF를 시장지수 대용으로 사용하는 실험이다. KOSDAQ에도 KODEX200을 쓰는 것은 별도 가설이다. 나스닥종합·QQQ·S&P500 지수를 혼용하지 않는다.
- 지수 월말은 각 시장 달력의 마지막 예정 거래일로 정한다. 조기폐장도 거래일이다. 해당 월말이 미확인이거나 종가가 누락되면 앞 날짜로 대체하지 않는다.
- 기준 시세가 불명확하면 A/B 모두 준비 상태로 두어 비교 시작의 차이를 줄인다. 뉴스 확인 실패도 A/B 공통 보류다. 기준 준비/미준비 및 필터 통과/보류 횟수는 관측 횟수이지 독립 거래 수가 아니다.
- 필터는 신규 매수와 가상 대기 매수의 체결 확인에만 적용한다. 기존 보유분은 일반 가격 청산 규칙을 계속 쓴다. 수입 포지션/stopOverrides는 두 장부에 가져오지 않는다.
- 시작 시 관심종목 최대 40개를 코드 순으로 고정한다. 이후 대시보드 관심종목 변경을 이 실험에 소급 적용하지 않는다. A/B의 현금·포지션·일일 한도·슬롯은 독립이므로 실제 체결 집합의 부분집합을 가정하지 않는다.

## 체결·비용 및 비교 기준

- 기존 가상 체결 엔진을 공유한다. 신호 뒤 최소 30초 후 다음 관측 가격에 편도 0.10% 불리한 체결과 0.15% 비용을 적용한다. 유동성/호가/부분체결/실제 세금표를 재현하지 않는다.
- 각 A/B 장부 3,000만 원, USD/KRW 고정 1,500. 실제 계좌 순수익이나 실제 환율 수익률로 해석하지 않는다.
- C: 같은 3,000만 원을 국내 KODEX200/미국 SPY에 절반씩 두고 각 시장의 다음 관측으로 정수 주식 수를 매수한 뒤 보유한다. 잔액은 현금, 월 리밸런싱 없음. C는 A/B보다 시장 노출이 높을 수 있으므로 수익률만으로 우위를 판단하지 않는다. 양 시장의 체결 시작 시각을 별도로 표시한다.
- 장이 닫혀 있으면 직전 예정 폐장 15분 이내의 관측을 종가 근사치로 유지한다. 임의로 오래된 시세는 허용하지 않는다. 장이 열려 있으면 15분 초과 시세를 오래된 것으로 처리한다. 폐장 근사 시세는 공식 종가가 아니다.
- 최대 역행/상승폭(MAE/MFE)은 진입 후 관찰한 가격의 진입 가격 대비 변화로, 비용 차감 기대수익이 아니다. 5분 표본이므로 관측 사이의 고가·저가/손절 도달을 놓칠 수 있다. 부분 청산 후에도 같은 포지션의 관측을 유지하고 완전 청산 시 닫는다.

## 수집과 저장

- `/api/strategy-comparison` GET은 상태 조회만, POST `{"action":"start"}` / `{"action":"stop"}`은 이 비교 수집만 제어한다. 브라우저 교차 출처 요청은 거부한다. 시작은 주문 잠금/모의매매 설정을 바꾸지 않는다.
- 시장이 열려 있을 때 5분 간격으로 KIS 모의 서버의 조회 API로 가격/일봉을 수집하고 뉴스 피드를 확인한다. 실제 주문 API를 호출하는 경로는 없다. 서버 재시작 후 수집은 정지하고 오래된 가상 대기 주문을 취소한다.
- 지수 이력은 공개 Yahoo 일봉의 원시/조정종가를 구분해 읽고 최대 6시간 캐시한다. 과거 뉴스나 과거 시세 스냅샷을 가진 백테스트가 아니라 앞으로 수집하는 실험이다. 제공처의 과거 조정주가 수정 가능성이 있으므로 조회 시점과 원본 스냅샷을 근거 파일에 저장한다. 결측 조정종가를 원시 종가로 대체하지 않는다.
- `.data/market-comparison-v1.json`은 검증 후 원자적으로 저장한다. `.data/market-comparison-v1-events.jsonl`에는 기준 시세 원본, 판단 입력, 뉴스 근거 ID와 가상 이벤트를 먼저 fsync한다. 크래시로 중복 근거가 생기면 이벤트 ID로 중복 제거해야 한다. 손상 기록을 자동으로 새 원장으로 덮어쓰지 않는다.
- 기존 증권사 주문 원장과 기존 뉴스 비교 파일을 재설정하지 않는다. 시세 조회에 따른 기존 진단 로그/카운터 갱신은 일어날 수 있다.

## 검증 범위

단위·통합 테스트는 월말 정확성/동점/결측/오래된 시세/미래 정보 제외, A/B 동일 체결, 필터 차이, 위험 청산 유지, 역행·상승폭, 휴장 후 시세의 유효성, 주문 없는 수집, 중지, 손상 원장 보존을 확인한다. 이 테스트 통과는 수익성 검증이 아니다. 독립 거래와 충분한 시장 구간이 쌓이기 전 승격하지 않는다.
