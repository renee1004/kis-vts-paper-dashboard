# 모의 전략 점검 및 변경

이 버전은 수익성을 보장하거나 검증된 승률을 제공하지 않습니다.
고정된 후보 규칙과 안전 검사, 재현 가능한 일봉 연구 도구를 추가했습니다.
코드는 실제 투자로 전환하지 않으며 기존 VTS 모의 활성화 절차를 유지합니다.

## 수정한 문제

- 부분 익절 체결을 보유 회차별로 기억하여 +10%에서 반복 반감하지 않습니다.
  일부만 체결된 부분 익절도 이미 수행한 것으로 취급해 추가 절반 주문을 막습니다.
- 매도 가능 수량은 앱의 주문번호로 확인한 순체결 수량과 증권사 잔고 중 작은 값이며,
  이미 제출한 미체결 매도 수량을 제외합니다. 기존 보유 종목에는 신규 혼합 매수도 하지 않습니다.
- 자동청산도 실행 상태, SAFE_LOCKED, autoExitEnabled, 시장 시간, 잔고 유효성을 확인합니다.
  토큰 발급/호출 대기 후 실제 주문 전송 직전에 다시 잠금을 확인합니다.
- 체결 원장은 500개 제한으로 지우지 않습니다. 반복 BLOCKED 진단만 100개로 제한합니다.
- 주문 전 의도를 파일에 기록합니다. 통신 결과가 불명확하면 UNKNOWN으로 보존하고
  확인 전 재주문 및 모든 신규 매수를 막습니다. 주문 번호가 없는 UNKNOWN은 증권사에서
  수동으로 확인해야 하며 자동 매칭/추정하지 않습니다.
- 이전 거래일 미체결은 해당 주문일의 체결을 확인한 뒤 잔여분을 만료 처리합니다.
  조회에서 빠진 주문은 체결 0으로 간주하지 않고 UNKNOWN으로 보존합니다.
- 파일 저장을 원자적 교체로 변경했습니다. 손상된 상태를 빈 계좌로 초기화하지 않습니다.
- 일일 손실 기준을 저장하고 재시작해도 유지합니다. 재시작 시 모든 주문 활성화 설정은 잠깁니다.
- KIS 체결 평균가를 기록합니다. 과거 체결가가 없거나 고아 매도 이력이 있으면 손익을
  확정하지 않고 신규 매수를 막습니다. 잘린 과거 원장이나 수동 매매를 추정 복원하지 않습니다.

## 후보 규칙 (trend-breakout-v1-unvalidated)

1. 해당 시장의 오늘 일봉은 제외하고 완료 일봉을 날짜순으로 정렬합니다. 65개 이상 필요합니다.
2. 매수: 종가 > 20일 평균 > 60일 평균, 60일 평균이 5거래일 전보다 상승,
   종가가 이전 20개 종가의 최대값 돌파, 20일 평균 대비 10% 이내,
   최근 20개 일간 수익률 표준편차 4% 이하를 모두 요구합니다.
3. 신규 진입 가격이 신호 종가에서 ±2% 이상 벗어나거나 일봉이 7일보다 오래되면 진입하지 않습니다.
4. 매도: 완료 일봉 종가가 20일 평균 아래로 하락하면 앱 보유분 매도 신호를 냅니다.
5. 최초 진입에서 정한 손절 폭은 일간 변동성의 2배, 최소 3%/최대 8%입니다.
   +10%에서 한 번 절반, +20%에서 나머지를 청산합니다. 손절은 손실 상한 보장이 아닙니다.
6. 동일 종목 추가 매수 없음, 동일 신호 재사용 없음, 매도 당일 재진입 없음.
7. 모의 전략 배정 예산 300만 원, 한 거래 예상 손실 위험 0.5% 이하로 수량 계산,
   종목당 10% 이하, 전체 50% 이하, 5종목 이하, 1회 기준금액 30만 원 이하,
   하루 매수 예약/체결 기준 합계 300만 원 이하입니다. 시장가 체결 변동과 비용은
   실제 사용액을 이 기준금액보다 크게 만들 수 있습니다.
8. 전략 손익 기준 당일 첫 유효 평가 대비 -2%면 신규 매수 차단,
   배정 예산 대비 누적 -20%면 앱 보유분 청산을 시도합니다.

조건 점수는 만족한 조건의 개수이며 확률이나 예측 승률이 아닙니다.
이 규칙은 장기 추세 추종이라는 연구 가설에서 출발한 별도 구현입니다.
다른 연구의 성과를 이 앱의 검증 결과로 사용하지 않습니다.

## 성과 측정과 제한

화면의 추정 손익은 확인된 체결가와 앱 보유분 평가액을 사용하지만,
편도 비용 0.15%, 달러당 1,500원의 고정 가정입니다. 실제 세금·환전 손익·수수료가
아니며 이 가정은 설정된 주문 예산과 함께 별도 검증해야 합니다. 외화 현금이 빠진
계좌 평가액이나 계좌 입출금을 전략 수익으로 섞지 않습니다.

해외 주문가능 현금 API를 추가한 버전이 아니므로 현금 부족 주문은 KIS가 거절할 수 있습니다.
시간 필터는 평일과 정규 시간만 반영하며 거래소 휴장·조기 폐장·거래정지는
별도 캘린더를 완성한 것이 아닙니다. KIS 거절을 자동 우회하지 않습니다.
체결조회 페이지 누락 및 장기 과거 조회 실패는 신규 매수 차단으로 처리합니다.
주식 분할/병합, 수동 매매, 계좌 변경이 있으면 앱 원장과 실제 계좌의 대조가 필요합니다.

## 검증 명령

```bash
node scripts/test-strategy.cjs
node scripts/test-backtest.cjs
node node_modules/next/dist/bin/next typegen
node node_modules/typescript/bin/tsc --noEmit
node scripts/backtest.cjs /path/to/dataset.json /path/to/report.json
```

백테스트 입력은 `{ "AAPL": { "fx": 1500, "bars": [{ "date": "20240102", "open": 100, "close": 101 }] } }`
형태입니다. 날짜 오름차순의 일관된 수정 시가/종가와 최소 65개 준비 기간이 필요합니다.
백테스트는 전일 완료 신호 → 다음 일봉 시가 체결 가정이며 KIS 분봉 체결 재현이 아닙니다.
장중 손절/일일 손실 차단, 주문 유동성, 시간대별 자금 사용 순서, 세금 및 실제 환율은
완전히 재현하지 않습니다. 기존 신호와 신규 신호 모두 같은 새 위험 한도로 비교합니다.

과거 결과만으로 신규 전략을 실전에 승격하지 않습니다. 같은 규칙을 고정한 채
앞으로 쌓이는 모의체결과 시장 비교, 비용 스트레스, 낙폭을 계속 기록해야 합니다.
